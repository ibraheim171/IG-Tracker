# إصلاح جامع إحصائيات إنستغرام

هذا الملف مخصص لمشروع Google Apps Script الخارجي المرتبط بـ Google Sheets، ولا يُشغَّل تلقائيًا من Vercel.

1. افتح `Code.gs` في مشروع Apps Script.
2. استبدل الدوال المطابقة بما في `analytics-collector-fix.gs` وأضف `metricValue_`.
3. احفظ، ثم شغّل `dailyPull` مرة واحدة وامنح الصلاحيات إن طُلبت.
4. راجع ورقة `log`؛ يجب أن يظهر `dailyPull + analytics sync ok`.

الإصلاح يرسل جمع اليوم تلقائيًا إلى الموقع ويحفظ القياس غير المتاح فارغًا بدل صفر مزيف. لا يمكن اختراع سلسلة 90 يومًا من قراءات لم تجمع سابقًا، لذلك الموقع يبيّن تغطية الأيام المقاسة بدل ادعاء إجمالي غير مكتمل.
